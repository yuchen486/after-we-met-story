# 相识以后

一篇以李向武为案例、关于相识与陪伴的互动感情故事。六个章节，从比赛相识、日常分享，到见面意向与学习表达，最后回到“认识你很好”。

**在线阅读：[打开《相识以后》](https://yuchen486.github.io/after-we-met-story/)**

## 阅读功能

- 连读与分章切换、章节链接、阅读进度。
- 夜读模式、字号调整、本地章节书签。
- 摘句选择与复制、完整 Markdown 正文下载、打印。
- 手机、平板和桌面自适应排版；尊重系统减少动态效果的设置。

## 本地使用

项目使用原生 HTML、CSS 与 JavaScript，无需安装依赖或构建。下载后打开 `index.html`，或在项目目录运行：

```sh
python -m http.server 8000
```

访问 `http://localhost:8000/`。

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面结构与原创 SVG 车窗插画 |
| `style.css` | 视觉、移动端、夜读与打印样式 |
| `story.js` | 六章正文、摘句与素材说明数据 |
| `app.js` | 阅读交互 |
| `相识以后.md` | 可下载完整正文 |

GitHub Pages 从 `main` 分支根目录发布。更新并推送页面后自动重新部署，`.nojekyll` 保持静态文件原样发布。

## 创作说明

作品基于用户既有叙述与可读聊天文字进行文学整理。街景、设想中的见面、读消息的动作、夜间场景和内心串联包含文学补写；未将想象的见面写成已经发生，也未替双方确认关系。详细说明可在页面文末展开查看。
